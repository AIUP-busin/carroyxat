# carroyxat

OLX.uz dagi **egasi sotayotgan** Chevrolet va elektromobil e'lonlari, xarid bo'yicha maslahatlar va ijara daromadi kalkulyatori.

- `index.html` — sayt
- `api/cars.js` — OLX'dan e'lonlarni yig'adi, perekup va salonlarni chiqarib tashlaydi (Vercel serverless funksiya)
- Natija Vercel'da 1 soat keshlanadi, ochiq sahifa ham har soatda o'zi yangilanadi.

## Vercel'ga qo'shish
1. vercel.com → Add New → Project → shu repo'ni Import qiling
2. Framework: **Other**, Build va Output sozlamalariga tegmang
3. Deploy
